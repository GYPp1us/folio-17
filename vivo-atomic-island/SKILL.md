# vivo 原子岛接入

## 思路

- 分别验证通知模板与场景授权：参考官方 demo 构造通知，核实当前 ROM 的授权入口和调用者权限。
- 正式发布走官方申请；个人自用可探索 shell 可调用的场景注册入口，将本机无线 ADB 客户端封装进 APK。仅修改本应用场景，保留其他配置。
- 用户配对、注册后关闭调试连接；日常由应用前台服务发布、更新和结束原子通知，无需电脑。
- 用授权回读、真实原子岛画面和断开 USB 后的操作验证结果。

## 配对要点

本应用先进入小窗，再以独立任务打开全屏开发者选项（`FLAG_ACTIVITY_NEW_TASK`）。保持系统配对弹窗可见，从应用小窗输入；配对端口与连接端口不同。两步各自显示本次结果，配对码不持久保存。

已验证：iQOO 15（`V2505A`），OriginOS 6，`PD2505B_A_16.0.30.14.W10`。新机型、新固件先复核接口与权限；OriginOS 7 尚未验证。
